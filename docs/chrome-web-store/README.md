# Chrome Web Store publishing

This directory contains everything that needs to be copied or uploaded to the Chrome Web Store Developer Dashboard.

## Files

- `LISTING-PT-BR.md`: English translation of the Brazilian Portuguese listing's name, summary, description, and public URLs; the content is now in English despite the original filename;
- `LISTING-EN.md`: English store listing;
- `PRIVACY-DISCLOSURES.md`: Purpose, permissions, data, and certifications;
- `REVIEW-INSTRUCTIONS.md`: Private test instructions for the review team;
- `SUBMISSION-CHECKLIST.md`: Complete sequence for the first publication and updates;
- `RELEASE-WORKFLOW.md`: ZIP generation and future automation;
- `screenshot-page/`: Sanitized local page based on WhatsApp Web's proportions;
- `assets/`: Upload-ready images and editable SVG sources.
