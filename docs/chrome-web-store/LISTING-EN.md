## Name

Transcriber for WhatsApp — Voice to Text

## Summary

Transcribe WhatsApp Web voice messages with Whisper and smart formatting. Open source, ad-free, with no intermediary server.

## Detailed description

Turn WhatsApp Web voice messages into text without leaving the conversation.

Transcriber for WhatsApp adds a button to each voice message. With one click, the selected audio is sent directly to Groq, converted to text by Whisper Large v3 Turbo, and, when needed, organized by GPT-OSS 20B. The transcript appears beside the message and can be copied immediately.

WHY USE IT

• Read voice messages when you cannot listen to them
• Transcription integrated into WhatsApp Web
• Automatic spoken-language detection
• Choose a colloquial, natural, or formal tone
• Optional formatting for paragraphs, dates, times, and lists
• Local cache that avoids transcribing the same message again
• Guided setup for creating and configuring a Groq API key
• Cancellation and progress indicators
• No ads, analytics, or intermediary server

PRIVACY

Nothing is transcribed automatically. Audio is sent to Groq only after you click to transcribe and accept the initial notice. Your API key and transcripts remain in the extension's local storage; you can clear the cache and remove the key at any time.

REQUIREMENT

You need to use your own Groq API key. API usage is subject to Groq's limits and terms.

OPEN SOURCE
